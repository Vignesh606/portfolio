# Vignesh Madineni — Developer Portfolio

Personal developer portfolio website built with Next.js 16 (App Router), Tailwind CSS v4, Lucide Icons, and HTML5 Canvas particle physics.

## ✨ Features

- **Interactive Canvas Dust Text:** Custom particle physics engine on the hero typography with organic dispersion, cursor wake/aerodynamic drag, and fluid spring restitution back to solid typography.
- **Dark Zinc Aesthetic:** Clean monochrome theme inspired by `parascodes.is-a.dev`, featuring subtle borders, status pills, and ambient glow.
- **Interactive Command Palette (`⌘K` / `Ctrl+K`):** Keyboard-navigable dialog to quickly jump across sections, open project repositories, copy contact email, and download the résumé.
- **Bento Projects Grid:** Categorized technical projects with live status indicators, architecture diagrams, and GitHub repository links.
- **Real-Time Sticky Index:** Desktop side-index with active section spy and smooth scrolling navigation.
- **Spotify Integration:** Embedded on-repeat single player and curated playlist with genre tags.
- **Guestbook & Discussions:** Community notes interface with local storage preview and direct link to GitHub Discussions for public messages.

## 🛠 Tech Stack

- **Framework:** [Next.js 16](https://nextjs.org) (Turbopack, App Router)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com)
- **Typography & Icons:** [Lucide React](https://lucide.dev)
- **Animation & Physics:** Vanilla Canvas 2D API with sub-pixel rendering and device pixel ratio adaptation
- **Language:** TypeScript 5

## 🚀 Getting Started

### Prerequisites

- Node.js 18+ (tested on Node v24)
- npm or pnpm

### Development

```bash
# Clone the repository
git clone https://github.com/Vignesh606/portfolio.git
cd portfolio

# Install dependencies
npm install

# Start local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

```bash
# Create optimized production build
npm run build

# Start production server
npm run start
```
